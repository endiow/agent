Python 装饰器的本质是什么？

装饰器本质上是一个高阶函数，它接受一个函数作为参数，并返回一个新的函数。
装饰器的作用是在不修改原函数代码的前提下，给函数添加额外的功能。

常见的装饰器用法包括：
- @staticmethod：将方法转换为静态方法
- @classmethod：将方法转换为类方法
- @property：将方法转换为属性访问

自定义装饰器示例：
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("函数执行前")
        result = func(*args, **kwargs)
        print("函数执行后")
        return result
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")
